# Logo Placeholder

Ten folder jest przeznaczony na logo organizacji/firmy.

## Jak dodać logo:

1. Przygotuj plik graficzny w formacie PNG, JPG lub SVG
2. Nazwij plik `logo.png` (lub odpowiednio dla innego formatu)
3. Umieść plik w tym katalogu
4. Zaktualizuj szablon certyfikatu, aby wykorzystywał logo

## Zalecane parametry:
- Format: PNG z przezroczystym tłem
- Rozmiar: 400x400 pikseli lub większy
- Orientacja: kwadratowa

## Tymczasowe logo:

Możesz wygenerować placeholder logo uruchamiając:
```bash
python3 create_logo.py
```

**Uwaga:** Wymaga zainstalowanych bibliotek z requirements.txt
